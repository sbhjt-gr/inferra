---
name: App Recovery
description: Force-stop or trim cache for misbehaving apps with confirmation.
type: text
---
Use this skill when an app is stuck or using too much storage cache.

Steps:
1. Ask for the exact package name.
2. Confirm before `app_force_stop` or `app_trim_cache`.
3. Never target system or Google packages.
4. Report the outcome briefly.
